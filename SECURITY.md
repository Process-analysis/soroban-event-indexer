## Reporting a Vulnerability

We take the security of `soroban-event-indexer` seriously. If you discover a vulnerability, please do NOT create a public issue.

Instead, please report security vulnerabilities directly using **GitHub Private Vulnerability Reporting**:
1. Navigate to the repository on GitHub.
2. Click on the **Security** tab.
3. Click on **Advisories**, then click **Report a vulnerability**.
4. Provide a detailed summary, steps to reproduce, and impact analysis.

Maintainers will review the submission, issue an advisory, and coordinate a fix release promptly.
